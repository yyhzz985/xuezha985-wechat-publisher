# 帮助文档

## 关于本插件

我日常创作主要在 Obsidian 里完成，同时也是**可能吧公众号排版器**的重度用户——那种简洁、克制、高级的排版风格正是我喜欢的。但每次写完文章都要跳出 Obsidian、打开网页、复制粘贴，工作流被硬生生切断，用起来很割裂。

于是我花时间做了这个插件，完整复刻了可能吧的排版风格，让从写作到发布的整个过程都能在 Obsidian 内完成。

特别鸣谢可能吧公众号排版器，本插件的排版样式完全参考自它，也非常推荐大家去可能吧公众号排版器的网站体验：
**https://mp.knb.im/**

---

## 快速开始

1. 在 Obsidian 左侧编辑器中打开或粘贴你的 Markdown 笔记
2. 点击左侧功能区的**公众号预览**图标，右侧将出现实时渲染效果
3. 如需调整样式，打开右上角**设置面板**查看可用选项
4. 写完后点击右上角**复制**图标，将内容粘贴到微信公众号后台
5. Pro 用户可点击**上传草稿箱**图标，将文章直接写入公众号草稿箱

> **复制逻辑**：未选中文本时复制整篇笔记；选中文本时优先复制选区内容。

---

## 免费复制与图片规则

免费复制不需要公众号 AppID、AppSecret，也不需要 Pro 授权。它只负责把当前文章排版成微信公众号编辑器可粘贴的 HTML。

图片分两种情况：

- **网络图片链接**：例如 `https://...`，复制后会保留原链接。只要微信后台能访问这个链接，图片就能显示。
- **本地图片**：例如 `![[图片.png]]`、`![alt](assets/image.png)`、`![alt](../attachments/image.png)`，预览里会按 Obsidian 当前笔记的位置解析并显示；但免费复制不会上传本地图片，所以手动粘贴到公众号后台后，本地图片不会显示。

如果文章里有本地图片，并且希望粘贴到公众号后台后也能显示，需要使用 Pro 的图片上传能力：复制时会先把本地图片上传到微信公众号正文图片接口，再把 HTML 里的图片地址替换成微信可访问的 URL。

插件不提供“图片目录配置”作为主方案。判断标准很简单：Obsidian 原生预览能解析到的图片，插件就复用同一套解析结果。

## 支持的语法

### 文本格式

| 写法 | 效果说明 |
|---|---|
| `**粗体**` | 加粗 |
| `*斜体*` | 斜体 |
| `~~删除线~~` | 删除线 |
| `` `行内代码` `` | 等宽行内代码 |
| `==高亮==` | 高亮强调 |
| `++下划线++` | 下划线 |
| `H~2~O` | 下标 |
| `x^2^` | 上标 |
| 中英混排 | CJK 与英文 / 数字之间自动加空格 |

---

### 标题

| 写法 | 效果说明 |
|---|---|
| `#` / `##` / `###` / `####` | H1 – H4 |
| `##` | H2 顶部显示阅读进度（开启「时间模块」时生效） |
| `###` | H3 自动章节编号（设置面板可切换编号风格） |
| `####` | H4 简洁加粗，无额外装饰 |

---

### 列表

| 写法 | 效果说明 |
|---|---|
| `- 项` / `* 项` | 无序列表（支持多级嵌套） |
| `1. 项` | 有序列表 |
| `- [x]` / `- [ ]` | 任务清单（勾选框自动替换为 emoji） |

---

### 引用与代码

| 写法 | 效果说明 |
|---|---|
| `> 文字` | 引用块（blockquote） |
| ` ```lang … ``` ` | 围栏代码块，Shiki 自动语法高亮，亮色 / 暗色主题可在设置中切换，支持横向滚动，适合粘贴较长代码 |

---

### 特殊容器

这些容器语法均可回写为 Markdown，后续仍可在 Obsidian 中继续编辑。

| 写法 | 效果说明 |
|---|---|
| `:::intro` | 摘要段，通常放在文章开头 |
| `:::highlight` | 金句强调，全句高亮 |
| `:::tip` | 提示框（💡 提示） |
| `:::info` | 说明框（🔵 说明） |
| `:::note` | 笔记框（📝 笔记） |
| `:::warning` | 警告框（⚠️ 注意） |
| `:::danger` | 危险框（☢️ 危险） |
| `:::say` | 单方独白 / 一段引述（💬 说） |
| `:::chat` | 多角色对话：行首写 **名字:** 开启新一轮对话（半角 / 全角冒号均可），无前缀的行自动续接到上一轮 |

冒号后可以加空格，例如 `::: tip`，效果与 `:::tip` 相同。

**使用示例：**

```
::: tip
这里是一条提示内容。
:::

:::chat
Alice: 你好！
Bob: 你好，很高兴认识你。
今天天气不错。
:::
```

### 链接 · 图片 · 其它

| 写法 | 效果说明 |
|---|---|
| `[文字](URL)` | 链接。公众号内链（`mp.weixin.qq.com`）保留可点击；其他外站链接自动改写为蓝色「文字（URL）」形式，避免读者找不到地址 |
| `![alt](URL)` | Markdown 图片，支持网络图片、本地相对路径和 URL 编码路径；`alt` 会显示为图片下方小字说明 |
| `![[图片.png]]` | Obsidian 图片嵌入，支持 `![[folder/image.png\|说明]]` |
| `\| 表头 \| …` | 标准 Markdown 表格（首行为表头 + 分隔线） |
| `:smile:` | emoji 短代码，例如 `:smile:`、`:rocket:`、`:sparkles:` |
| `[^1]` / `[^1]:` | 脚注，文末自动汇总 |
| `[TOC]` | 全文导航：在该位置按 H2 列出章节目录 + 阅读进度条（必须独占一行，且全部大写） |
| `---` | 分隔线 |

脚注示例：

```
正文里引用脚注[^1]。

[^1]: 这里是脚注内容。
```

## 排版设置

点击右上角**齿轮图标**可打开设置面板，支持调整：

- **主题**：亮色 / 暗色
- **字重**：正文字体粗细
- **小标题风格**：H3 编号样式
- **代码主题**：代码块高亮配色
- **顶部时间模块**：开启后在顶部显示作者、头像和阅读时间
- **作者名 & 头像 URL**：显示在顶部时间模块中；手动填写图片链接是免费功能，上传本地头像图生成公众号可用图片链接是 Pro 功能

## 公众号草稿箱上传（Pro）

> 此功能为 **Pro 专属**，需填写 License Key 后激活。

配置完成后，可一键将文章直接上传至微信公众号草稿箱，无需手动复制粘贴。上传草稿箱和 Pro 复制都会处理本地图片：先按 Obsidian 解析结果读取图片，再上传到微信公众号正文图片接口，最后替换成微信图片 URL。

### 配置步骤

在设置面板的「公众号上传配置」区域填写以下信息：

微信开发者平台：https://developers.weixin.qq.com/platform

| 字段 | 说明 | 获取方式 |
|---|---|---|
| **AppID** | 公众号唯一标识 | 在公众号后台→ 设置与开发 → 账号设置丨或者到微信开发者平台获取 |
| **AppSecret** | 接口调用密钥 | 到微信开发者平台获取，只显示一次，若忘记需重置 |
| **默认封面 media_id** | 上传草稿时使用的封面图 | 可手填，也可点击「上传封面图」按钮自动生成 |
| **服务器 IP 白名单** | AppSecret 调用所需的 IP 授权 | 在公众号后台 → 设置与开发 → 安全中心 → IP 白名单中配置；本插件从本机发起请求，填写**本机公网 IP** 即可，可访问 https://myip.ipip.net/ 一键查询 |

> **注意**：家用宽带通常为动态公网 IP，运营商可能不定期更换。如果某天上传草稿突然失败，优先重新访问 https://myip.ipip.net/ 确认当前 IP 是否有变化，重新填入白名单即可恢复。

上传头像图也使用公众号图片上传能力。它不是普通本地预览功能，需要 Pro 授权、AppID、AppSecret 和微信 IP 白名单都配置正确。

### 安全说明

- AppSecret 明文保存在当前 Obsidian 库的插件数据里，**不会上传到任何授权服务器**
- 文章内容与公众号密钥不会经过第三方服务器中转
- 授权服务器只校验 License Key、设备 ID、插件 ID、插件版本和功能名，不接收文章正文或公众号密钥

### 上传后的行为

- 原文链接会按设置写入草稿
- 开启评论后，上传草稿时会允许文章留言评论
