# 产品定义

## 一句话

本项目为使用 Obsidian 写作的公众号作者构建 `公众号一键排版上传`，通过把 Markdown 笔记转换成微信公众号可用 HTML、预览、剪贴板内容和 Pro 草稿上传，解决写完文章后还要离开写作环境去排版的问题。

## 用户和痛点

| 字段 | 内容 |
| --- | --- |
| 用户 | 公众号写作者、自媒体作者、在 Obsidian 写 Markdown 的内容创作者 |
| 痛点 | 写完文章后还要打开网页排版器、复制、粘贴、处理图片和公众号后台格式 |
| 频率 | 每次公众号文章发布前 |
| 当前替代方案 | 从 Obsidian 复制到网页排版器，再复制到微信公众号后台 |
| 替代方案的问题 | 工作流被切断，格式口径容易漂移，本地图片和草稿上传需要额外手工处理 |

## MVP

| 字段 | 内容 |
| --- | --- |
| 输入 | 当前 Obsidian Markdown 笔记、选中文本、插件设置、本地或网络图片 |
| 处理 | 清理 frontmatter，解析 Markdown，生成可能吧风格内联 HTML，按授权状态处理图片和上传能力 |
| 输出 | 右侧实时预览、可粘贴到微信公众号后台的 HTML、Pro 草稿箱上传结果 |
| 不做 | 不直接群发文章，不自动发布生产 Worker，不自动收款发卡，不管理公众号多账号 |

## 14 天验证

成功标准：

- 用户能在 Obsidian 内完成预览和复制，不需要打开网页排版器。
- `npm test` 和 `npm run build` 稳定通过。
- 最新 Release 资产包含 `manifest.json`、`main.js`、`styles.css` 和 zip。
- 用户文档、帮助面板和 README 对免费/Pro 边界说明一致。

失败信号：

- 微信公众号后台粘贴效果明显偏离预期。
- 免费复制误要求 AppID、AppSecret 或 License。
- Pro 上传把文章正文、AppSecret 或 License 发到授权服务器。
- 修改后没有测试或构建证据。

## 风险和假设

- 假设核心用户已经会写 Markdown，并愿意安装 Obsidian 第三方插件。
- 微信公众号编辑器会过滤或改写部分 HTML/CSS，渲染规则需要回归测试锁定。
- Worker、D1、License 发卡属于生产风险区，不能在普通代码任务里顺手改。
- Root `main.js` 是生成产物但被跟踪，源码改动后必须同步构建产物。
